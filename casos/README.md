# Banco de casos

Ativo reutilizável entre episódios. Criado em 6/ago/2026 porque a falha de acionabilidade do ep. 5 não foi falta de esforço, foi **falta de repertório**: eu não tinha casos concretos à mão, e o Sobral usado no ep. 3 não foi reaproveitado.

**Regra**: todo caso precisa de número verificável, fonte e — obrigatoriamente — o **contra-argumento**. Caso sem contra-argumento é propaganda, não caso.

**Como usar**: consultar antes de escrever qualquer roteiro. Se um eixo do debate não tem caso concreto disponível aqui, ou se pesquisa um, ou se declara na revisão que o eixo ficou abstrato.
